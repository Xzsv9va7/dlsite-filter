# DLsite 作品フィルタ

DLsite の作品一覧・検索結果で、指定したサークル名・作品名・ジャンルに一致する作品を非表示にするブラウザ拡張機能です。

DLsite / 株式会社エイシス公式ではありません。利用は自己責任でお願いします。

## できること

- サークル名、作品名、ジャンル名を指定して作品を非表示にする
- 部分一致、または `"名前"` / `「名前」` で囲んだ完全一致
- 一覧にジャンルが出ていないとき、作品詳細ページからジャンルを取得する（オフにできる）
- 設定の JSON エクスポート / インポート（結合または上書き）

## インストール

[Releases](https://github.com/Xzsv9va7/dlsite-filter/releases) から、使っているブラウザ向けのファイルをダウンロードしてください。

| ブラウザ | ファイル |
| --- | --- |
| Firefox | `.xpi` |
| Chrome / Edge | `.zip` |

### Firefox

署名済みの `.xpi` を入れます。Firefox 142 以降が必要です。

1. Releases から `.xpi` をダウンロードする
2. アドレスバーに `about:addons` と入力してアドオン管理を開く
3. 歯車アイコンから「ファイルからアドオンをインストール」を選ぶ
4. ダウンロードした `.xpi` を選択し、追加を許可する

同じ ID の新しい `.xpi` を入れ直すと更新できます。

試すだけなら `about:debugging` → 「この Firefox」→ 「一時的なアドオンを読み込む」で `manifest.json` を選べます。この方法は Firefox を終了すると消えます。常用する場合は `.xpi` を使ってください。

### Chrome / Edge

デベロッパーモードで読み込みます。

1. Releases から `.zip` をダウンロードして解凍する
2. アドレスバーに `chrome://extensions`（Edge は `edge://extensions`）と入力する
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックする
5. 解凍したフォルダのうち、`manifest.json` がある階層を選ぶ

デベロッパーモードを切ると拡張が無効になります。更新するときは、新しい zip の中身でフォルダを差し替えてから、拡張の「再読み込み」を押してください。

## 使い方

1. ツールバーの拡張アイコンをクリックして設定画面を開く
2. 非表示にしたいサークル名・作品名・ジャンルを、1行に1つずつ入力する
3. 保存する
4. DLsite の一覧・検索結果を開く（すでに開いている場合は再読み込みする）

一致のしかた:

- 囲まない → 部分一致（`ボイス` は「ボイス作品」などにも当たる）
- `"ボイス"` や `「ボイス」` で囲む → 完全一致

ジャンルが一覧に出ていない作品まで見たい場合は、「作品詳細ページからジャンルを取得する」をオンにします。オフのままだと、そのための通信は行いません。

サークル名・作品名で既に非表示になった作品には、ジャンル取得のためのアクセスはしません。取得したジャンルはブラウザ内に最大 90 日（または 5,000 件）キャッシュします。設定画面からキャッシュを消せます。

## 権限とデータの扱い

| 権限 | 用途 |
| --- | --- |
| `storage` | 設定とジャンルキャッシュを端末内に保存する |
| `https://www.dlsite.com/*` | 作品の非表示処理、および（オン時のみ）ジャンル取得 |

設定もキャッシュもブラウザの拡張機能ストレージにだけ保存します。開発者のサーバーへユーザーデータを送ることはありません。ネットワーク通信は、ジャンル詳細取得をオンにしたときに DLsite の作品詳細ページへアクセスする場合だけです。

## 既知の制限

- ランキングで作品を非表示にすると、画面上の順位番号はそのまま残るため、並びと実際の順位がずれて見えることがあります
- Chrome / Edge の手動インストール、および GitHub 配布の `.xpi` に自動更新はありません。更新は Releases から入れ直してください
